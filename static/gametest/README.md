# gametest

This folder is owned by the game studio. The site build copies it byte-for-byte to `dist/gametest/` and GitHub Pages serves it at `/gametest/`. It is not part of the Index Agentica directory (noindex; excluded from the sitemap, IndexNow, llms.txt, the JSON API, and usage stats). A `README.md` here is served as a file, not as an HTML page; `/gametest/` is served only when `index.html` is present.

Studio workflow, size limits, and commit rules: [README.md#gametest](../../README.md#gametest).
